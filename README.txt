LIGHTHOUSE PETROLEUM WEBSITE

This folder contains the complete static website.

Main file:
- index.html

Supporting files:
- styles.css
- sky-theme.css
- parallax.css
- script.js
- lighthouse-logo.png

To preview on a computer, open index.html in a web browser.

To publish with GoDaddy Web Hosting, upload every file in this folder to the
hosting account's public_html directory. Keep all filenames together in the
same directory so the styles, animation, and images load correctly.

The website is also currently hosted at:
https://lighthousepetroleum.com
